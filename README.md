## AI in Practice — From Conversation to Order

This illustrative walkthrough shows the WhatsApp kottu-order flow: the assistant clarifies the variety, checks whether the customer wants anything else, and then deterministic application code calculates the total. The final response uses the order number supplied by the backend. No real customer data, prices, or order IDs are shown.

**[▶ Launch the interactive AI workflow demo](https://piraveen17.github.io/Piraveen17/ai-workflow-demo.html)**

| Stage | What happens |
| --- | --- |
| **01 · Clarify** | Customer asks for two kottu. The assistant asks whether they want egg, chicken, mutton, or beef. |
| **02 · Capture** | Customer selects egg kottu. The assistant asks if they want to order anything else. |
| **03 · Calculate** | Customer says no. Deterministic application code uses the applicable system price to calculate the total. |
| **04 · Respond** | Customer receives the backend-provided order number and the code-calculated total. |

> **Engineering principle:** the assistant clarifies intent; reliable application code calculates prices and supplies system-generated order details.
